Stairs VERSION for Rhino 8 / 9
============================

This download contains the Rhino plug-in (Stairs.rhp), the Grasshopper
components (StairsGen.gha), these instructions and the license. Both files work
on macOS and on Windows.

The easiest install is Rhino's Package Manager: run PackageManager, search for
StairsGen and click Install. It installs both, and updates them.


REQUIREMENTS

- Rhino 8 / 9. On Rhino 8, Service Release 35 or later.
- Rhino's default .NET runtime. On Windows: if Rhino was ever switched to
  .NET Framework with the SetDotNetRuntime command, switch it back.


INSTALL ON MACOS

1. Unzip the download.
2. Copy Stairs.rhp into this folder (8.0 for Rhino 8, 9.0 for Rhino 9):
   ~/Library/Application Support/McNeel/Rhinoceros/9.0/MacPlugIns/
   (In Finder, choose Go > Go to Folder... and paste the path.)
3. For the Grasshopper components, copy StairsGen.gha into this folder:
   ~/Library/Application Support/McNeel/Rhinoceros/9.0/Plug-ins/
     Grasshopper (b45a29b1-4343-4035-989e-044e8580d9cf)/Libraries/
4. Restart Rhino.


INSTALL ON WINDOWS

1. Unzip the download. Keep Stairs.rhp in a permanent folder: Rhino loads it
   from there every time it starts.
2. If Windows marks the file as downloaded, right-click Stairs.rhp, choose
   Properties, tick Unblock and click OK.
3. Start Rhino and drag Stairs.rhp onto the Rhino window.
   (Or choose Tools > Options > Plug-ins > Install... and pick Stairs.rhp.)
4. For the Grasshopper components, open Grasshopper, choose File > Special
   Folders > Components Folder, copy StairsGen.gha there (Unblock it too) and
   restart Rhino.


USE

Run the StairsGen command and click points along the stair (Enter finishes),
or use its SelectCurve option to pick a flat curve already in the model. The
PlugInManager command lists Stairs once it is loaded.

In Grasshopper the components are on the StairsGen tab: start with Stair (a
curve and a height), then add Landings, Pyramid or Autoconfigure, and build its
Structure, Railing and Step Numbers.

To update: close Rhino, replace Stairs.rhp and StairsGen.gha with the new
ones, and start Rhino again.
